# 3.0 研究记录：现有产品、监管制度与实务案例

编写：ClawsGO Science Agent。检索日期：2026-11-09。本文件是金融论证的证据底稿，《授信模式设计与创新性对照.md》中的判断均可回溯到这里。

检索方式：两个子智能体分别检索监管制度和工行产品，主智能体打开原文抽查了关键条款（标"主智能体复核"）。核验程度分三级：已核原文、转载核对、仅检索摘要。只有检索摘要的内容不作为设计依据，只作背景。

## 三、实务案例（媒体或政府发布，非产品条款）

- 工行百色靖西支行为经互市进口越南腰果的加工企业发放300万元"兴农制造贷"，担保公司三七分险。工行百色分行累计支持14家落地加工企业超6000万元（[农村金融时报网，2026-06-11](https://www.zhgnj.com/content/202606/11/c27332554.html)）。未披露额度核定方法。
- 工行防城港分行在"经营快贷"基础上发放数字人民币"边民贷"（[中新网广西，2025-10-11](http://www.gx.chinanews.com.cn/byxx/gxicbc/2025-10-11/detail-ihevwnnh9888846.shtml)）。
- 工行崇左分行"外贸进出口产业集群e贷"整合桂信融、税务和海关数据（[人民周刊网，2025-07-18](https://www.peopleweekly.cn/html/2025/caijing_0718/252559.html)）。
- 桂林银行"惠边贷"：借款人为落地加工企业，企业自筹30%、银行提供70%，定向支付并跟踪资金流向，可单笔或循环，最长3年（桂林银行官网产品页）。
- 中国银行防城港分行按不超过纳税收入30%核定落地加工企业信用额度（[人民网，2023-11-28](http://finance.people.com.cn/n1/2023/1128/c1004-40127149.html)）。
- 建设银行广西区分行线上"边民贷"直连广西边民互市贸易综合服务平台订单数据建模授信（网易转载，2026-09-14）。

这些案例说明：落地加工企业的采购融资、以订单或平台数据核额、定向支付，在银行业已有实践。本项目不能把这些功能当作自己的创新。
