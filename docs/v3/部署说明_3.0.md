# 部署说明：手动上传 Demo 3.0 到腾讯云 CloudBase 静态网站托管

编写：ClawsGO Science Agent，2026-11-10。本阶段未登录或修改任何腾讯云环境。以下步骤由有权限的人员确认后自行操作。2.0 的部署说明（`DEPLOY_CLOUDBASE.md`）仍然适用，本文只列 3.0 的差别。

## 1. 上传什么

上传"CloudBase_3.0静态部署文件"目录中的内容，或其压缩副本"CloudBase_3.0静态部署包.zip"（ZIP 根目录直接是 `index.html` 等文件）。

| 文件 | 说明 |
| --- | --- |
| `index.html` | 站点入口，单文件页面，1 950 708 字节 |
| `demo.html` | 与 `index.html` 字节一致 |
| `THIRD_PARTY_NOTICES.txt` | 第三方许可声明 |
| `SHA256SUMS.txt` | 校验和 |

`index.html` 的 SHA-256 应为 `d7b35375c70c9c349b2cf56bbba55e162694c56f2dee01dcdf567d72026b390e`。

## 2. 上传前要决定的事

原演示地址当前为 v1.0，2.0 尚未上传。覆盖根目录 `index.html` 后，原二维码会直接打开 3.0。可选做法：

- 直接覆盖：先在控制台下载备份现有 `index.html`、`demo.html` 与 `assets/`。
- 保留多个版本：把 3.0 上传到子目录（例如 `/v3/`），访问 `/v3/index.html`；页面不引用任何相对路径资源，放在子目录可以正常运行。

3.0 的浏览器存储键为 `bianmao.v3`，与 2.0 的 `bianmao.v2` 互不影响。

## 3. 上传与验证

上传步骤与 `DEPLOY_CLOUDBASE.md` 第3节相同。上传后用无痕窗口验证：

1. 根地址：标题"工银边贸智链｜边民互市经营协同与融资需求联动平台"，八个工作区。
2. `?scene=translate`：待筹10.672万元、第40日至第42日、清偿第44日→第54日（2.0 数值不变）。
3. `?scene=financing`：出现"融资支持方案说明（批次专项提款·模拟）"，下限10.672万元、上限13.608万元。
4. 在该页点"在第20日历史匹配情景中对照"，出现"匹配后保留3,969条"，说明计算线程在该域名下可用。
5. 手机扫码打开，确认可以切换工作区。

## 4. 回退

重新上传备份的旧文件即可。2.0 的部署文件在 `交付成果\CloudBase_静态部署文件\`。
